=== PART 1: FIX VB-07 (the actual bug) ===

At roughly line 144-146 the component builds record results:

    key: `record-${group.model}-${item.id}`,
    label: item.title,
    sub: group.model,          // <-- BUG

`group.model` is the raw model KEY, so a record result reads "order_item" instead of
"Order Items". Note the model entries a few lines below already do this correctly,
using `m.verbose_name_plural`.

Fix it:
1. Build a lookup from the `models` prop, near the other useMemo hooks:

       const modelLabelByName = useMemo(() => {
         const map = new Map<string, string>();
         (models ?? []).forEach((m: any) => {
           if (m?.name) map.set(m.name, m.verbose_name_plural ?? m.verbose_name ?? m.name);
         });
         return map;
       }, [models]);

2. Change the record result to:

       sub: modelLabelByName.get(group.model) ?? group.model,

   Keep the `key` field exactly as it is — it is an internal React key, not display text.
