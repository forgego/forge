one `index` chunk. Convert each non-default route to a lazily-loaded component so
only the route the user actually opens is fetched.

src/routes/index.tsx first to learn the exact `createFileRoute` shape in use, then
apply the same shape everywhere.

version in package.json supports it — check with:

    grep '"@tanstack/react-router"' package.json
