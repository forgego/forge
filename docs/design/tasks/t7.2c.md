Palette color -> semantic token:

  rose-* / red-*                 -> danger         (bg-danger-surface, border-danger/20, text-danger)
  amber-* / yellow-* / orange-*  -> warning        (bg-warning-surface, border-warning/20, text-warning)
  blue-* / sky-* / cyan-*        -> info           (bg-info-surface, border-info/20, text-info)
  indigo-* / violet-* / purple-* -> primary        (bg-primary/10, border-primary/20, text-primary)
  zinc-* / slate-* / gray-* / neutral-* / stone-*:
      as body text      -> text-foreground
      as secondary text -> text-muted-foreground
      as a surface      -> bg-surface-sunken  (or bg-surface-2 for a card)
      as a border       -> border-border-subtle  (or border-border)
Raw hex in a chart -> hsl(var(--chart-N)) via src/lib/chart-theme.tsx (import chartColor / CHART_COLORS).
