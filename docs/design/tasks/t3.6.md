=== INTENT ===
Section 6 permits motion in exactly five places. This task implements ONE of them:
the active-nav indicator glides between nav items instead of blinking on and off.
It is the single memorable motion in the shell.

**Do NOT add route transitions.** Operators navigate hundreds of times a day and a
staged page fade makes the tool feel slower. Only the indicator animates.

=== CURRENT STATE ===
Several nav entries (the Dashboard link, pinned-model buttons, model buttons) render
an active indicator like this:

    <span
      aria-hidden
      className="absolute left-0 top-1/2 h-5 w-[3px] -translate-y-1/2 rounded-full bg-primary"
    />

Each one mounts and unmounts independently, so the bar pops rather than moves.

=== THE CHANGE ===
1. Import at the top:
       import { motion, LayoutGroup } from "framer-motion";
       import { useReducedMotion } from "framer-motion";

2. Wrap the whole <nav> element's children in a single <LayoutGroup id="admin-nav">.

3. Replace EVERY occurrence of that indicator <span> with:

       <motion.span
         aria-hidden
         layoutId="admin-nav-indicator"
         className="absolute left-0 top-1/2 h-5 w-[3px] -translate-y-1/2 rounded-full bg-primary"
         transition={
           prefersReducedMotion
             ? { duration: 0 }
             : { type: "spring", stiffness: 520, damping: 38 }
         }
       />

   All of them must share the SAME `layoutId` string — that is what makes the bar
   travel from the old item to the new one.

4. In the AdminLayout component body add:
       const prefersReducedMotion = useReducedMotion();
   and pass it down to wherever the indicator is rendered. If an indicator lives
   inside the module-scope `SidebarItem` component, add a `prefersReducedMotion?: boolean`
   prop to `SidebarItemProps` and pass it from the call site — do NOT call a hook
   inside a non-component helper.

5. Only ONE indicator may be rendered at a time across the whole nav. Since the
   existing code renders it only when an entry is active, confirm that at most one
   nav entry can be active simultaneously. If the Dashboard link and a model button
   could both be active, gate the model indicator on the Dashboard not being active.
