=== BACKGROUND ===
In the table body, `displayFields.map((fieldName, colIdx) => { ... })` renders each
cell. Today a foreign-key column just falls through to `val?.toString()`, so an FK
renders as a bare number like `0` with no indication of what it points at. Separately,
empty values are rendered inconsistently, and boolean cells use hardcoded Tailwind
palette colors (emerald-500 / rose-500) that the design system forbids.

This task is Phase 1 of the FK fix (Appendix B). It does NOT need any backend change:
an FK cell will render a LINKED `#<id>` instead of a bare number. A later task adds
real labels.

=== STEP 2: build a relation lookup ===
Near the other useMemo hooks in the component, add:

    const relationByField = useMemo(() => {
      const map = new Map<string, any>();
      (metadata?.relations ?? []).forEach((rel: any) => {
