# Docs Index

Docs describe intent and current understanding, not proof.
A feature listed in `PRD.md`, `DESIGN.md`, or `ROADMAP.md`
is a target until verified against code, schema, tests,
and running behavior.

## Public product docs

- [Product requirements](PRD.md) — product requirements and scope.
- [Design](DESIGN.md) — architecture, invariants, subsystem design.
- [Roadmap](ROADMAP.md) — proposed sequence and future direction.
- [Technical debt](TECH-DEBT.md) — recorded maintenance concerns.
- [Known bugs](BUGS.md) — recorded defects; verify status against current code.
- [Review standard](REVIEWING.md) — flow, architecture, naming, and test evidence.
- [Documentation policy](DOCUMENTATION-POLICY.md) — public/local ownership and maintenance.
