# QuerySet

QuerySet provides composable filters, ordering, and pagination.
Calls chain; every chaining method returns a new QuerySet.

## Core methods

- `Filter`, `Exclude`
- `OrderBy`, `Reverse`
- `Limit`, `Offset`, `Distinct`
- `Select`, `Only`, `Defer`
- `SelectRelated`, `PrefetchRelated`
- `Aggregate`, `Annotate`
- `Values`, `ValuesList`
- `All`, `Get`, `First`, `Last`, `Count`, `Exists`
- `Update`, `UpdateBuilder`, `BulkUpdate`
- `Delete`
- `Union`, `Intersection`, `Difference`
