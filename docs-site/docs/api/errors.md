# API Errors

The API layer provides exception types and error codes with problem details.

## Exception types

- AuthenticationFailed
- NotAuthenticated
- PermissionDenied
- Throttled
- NotFound
- MethodNotAllowed
- ParseError
- UnsupportedMediaType
- Validation

## Error codes

Error codes are registered and can be documented via the error registry.
