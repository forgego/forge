# Introduction

forge is a Django-inspired Go framework for database-backed applications. It ships a type-safe ORM, admin UI, REST API layer, migrations, and code generation in one workflow.

## What you can do

- Define schemas with fields, relations, metadata, and hooks
- Query data with a type-safe ORM
- Manage data with an auto-generated admin UI
- Expose APIs with serializers, auth, and pagination
- Generate and apply migrations

## When to use forge

Use forge when you want Django-like productivity in Go without sacrificing type safety or performance.
