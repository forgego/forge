# Middleware

Default middleware includes request ID, logging, recoverer, and timeouts.

## Default stack

- RequestID
- RealIP
- Recoverer
- Logger
- Timeout

## Additional middleware

- CORS
- Compress
- SecureHeaders
- StripSlashes, RedirectSlashes
