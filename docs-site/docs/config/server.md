# Server Settings

- Host, Port
- ReadTimeout, WriteTimeout
- StaticFilesPath
- HealthCheckPath
- MetricsEnabled, MetricsPath
- GracefulTimeout
- MaxRequestSize
- EnableProfiling
- InfoEndpoint (`server.info_endpoint`, default `false`): registers `/info`,
  which reports app name, version, environment, debug flag and uptime
