# Forge Admin UI

React + TypeScript + Vite admin interface for Forge models. Served
embedded by the Go backend (`forge/admin/ui`) with a `web/dist`
fallback for development.

## Develop

```bash
npm install
npm run dev      # Vite dev server
npm run build    # tsc + vite build into dist/
npm test         # vitest (run once: vitest run)
npm run lint     # eslint, must be error-free
```

## Conventions

- shadcn-style primitives live in `src/components/ui/`.
- Data access goes through `src/api/client.ts` (`adminAPI`) and
  `src/api/hooks/adminHooks.ts` — no ad-hoc fetch calls.
- Path alias `@/*` maps to `src/*`.
- Keep `routeTree.gen.ts` fresh (regenerated by the TanStack
  Router plugin during build); never hand-edit it.
